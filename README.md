# 🔥 Dennis AI — Local Llama Chatbot

A simple local AI chatbot built using **Streamlit**, **Ollama**, and **Llama 3.2**.

This project runs entirely on your local machine, meaning your conversations stay private and no data is sent to external AI providers.

---

## 🚀 Features

- Local LLM execution using Ollama
- ChatGPT-style conversational UI
- Streaming responses (real-time typing effect)
- Session-based chat memory
- Lightweight and beginner-friendly
- Privacy-first AI experience

---

## 🛠️ Tech Stack

| Layer            | Technology    |
| ---------------- | ------------- |
| UI Layer         | Streamlit     |
| State/Memory     | session_state |
| AI Backend       | Ollama        |
| LLM              | Llama 3.2     |
| Streaming Engine | stream=True   |
